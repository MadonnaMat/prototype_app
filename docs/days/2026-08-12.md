## Model

**`Task`** — simple, demoable CRUD resource (title, description, done flag):

```bash
bin/rails generate model Task title:string description:text done:boolean
```

- `title:string` — required (`validates :title, presence: true`)
- `description:text` — optional
- `done:boolean` — `default: false, null: false` in the migration
- `bin/rails db:migrate`

## Routes

Keep it a JSON API under `/api`, separate from the `pages#home` SPA shell:

```ruby
namespace :api do
  resources :tasks
end
```

Gives you: `GET/POST /api/tasks`, `GET/PATCH/DELETE /api/tasks/:id` — covers index/show/create/update/destroy from the checklist.

## Controller

`Api::TasksController` (new `app/controllers/api/` namespace):
- `index` → `render json: Task.all`
- `show` → `render json: @task`
- `create` → `Task.new(task_params)`; `render json: @task, status: :created` or `render json: @task.errors, status: :unprocessable_entity`
- `update` → same success/failure pattern with `:ok`
- `destroy` → `@task.destroy; head :no_content`
- Private `task_params = params.require(:task).permit(:title, :description, :done)`
- `set_task` `before_action` for show/update/destroy (404 via `find` raising `ActiveRecord::RecordNotFound`, let it bubble to Rails' default JSON 404 or rescue explicitly if you want a clean `{ error: "not found" }` body)

## Tests (Minitest, since that's the Rails default here — no rspec installed)

- `test/controllers/api/tasks_controller_test.rb` — one assertion per action: index returns 200 + array, create with valid/invalid params (201/422), update, destroy (204), show missing id (404)
